Python 是一种解释型、面向对象的高级编程语言，广泛应用于数据科学、Web 开发和自动化脚本。
Flask 是一个轻量级的 Python Web 框架，适合快速构建 API 和后端服务。
Docker 是一个容器化平台，可以将应用及其依赖打包成镜像，实现环境一致性部署。
Nginx 是一款高性能的 HTTP 和反向代理服务器，常用于负载均衡和静态文件服务。
Redis 是一个内存中的键值存储系统，常被用作缓存、消息队列和会话存储。
Git 是分布式版本控制系统，用于跟踪代码变更和多人协作开发。
Linux 是一种开源操作系统内核，广泛用于服务器、嵌入式设备和云计算环境。
SQLite 是一个轻量级的关系型数据库，不需要独立的服务器进程，适合小型应用和原型开发。
机器学习是人工智能的一个分支，通过数据和算法让计算机从经验中学习规律。
RAG（检索增强生成）是一种将信息检索与大语言模型结合的技术架构，先检索相关知识再生成回答。
